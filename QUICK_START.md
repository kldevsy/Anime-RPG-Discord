# ⚡ Quick Start - 30 Segundos

## 🎯 Como Iniciar o Bot

### Na Replit:

1. **Clique no botão verde "Run" ▶️**
2. Aguarde ~30 segundos
3. Bot online! ✅

---

## 📱 Opções Rápidas

### No menu lateral da Replit (workflows):

```
🚀 Start Bot        → Inicia tudo (padrão)
⚡ Quick Restart    → Reinicia rápido (5s)
🔄 Full Restart     → Do zero (30s)
📊 Apply Migrations → Atualiza banco
🔨 Build Only       → Compila código
🎲 Seed Characters  → Atualiza personagens
```

---

## 🐚 No Shell (se preferir):

```bash
# Tudo de uma vez
./start.sh

# Só reiniciar (rápido)
./start.sh quick

# Só build
./start.sh build

# Só migrations
./start.sh migrate
```

## 🆘 Problemas Comuns

### Bot não responde?
→ **Quick Restart**

### Erro "table não existe"?
→ **Apply Migrations**

### Mudou código?
→ **Start Bot** (rebuild automático)

### Tudo bugado?
→ **Full Restart**
