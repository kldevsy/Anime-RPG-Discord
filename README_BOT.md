# 🤖 Anime RPG Discord Bot

## ⚡ Início Rápido

### Na Replit:
1. **Clique no botão "Run" ▶️**
2. Aguarde 30 segundos
3. **Bot online!** ✅

## 🎮 Comandos Principais

### Perfil & Coleção
```
/perfil ver          → Ver perfil completo com stats
/perfil showcase     → Escolher 3 personagens favoritos
/perfil banner       → Definir banner do perfil
/perfil bio          → Escrever bio
/personagens         → Ver sua coleção
/equipe ver          → Ver equipe atual
```

### Gacha & Invocação
```
/invocar             → Invocar personagens
/banner              → Ver banners ativos
```

### Batalhas
```
/arena              → Batalha PvP adaptativa
/batalha            → Batalha PvE
/bossrush iniciar   → Boss Rush (5 bosses consecutivos)
/raid criar         → Criar raid cooperativa
```

### Economia & Missões
```
/diario             → Recompensa diária
/missoes            → Ver e completar missões
/ranking            → Leaderboards
/loja               → Loja de loot boxes
```

### Equipamentos
```
/equipamento equipar     → Equipar item
/equipamento inventario  → Ver equipamentos
/equipamento catalogo    → Ver catálogo
```

## 🔥 Features Principais

### ✨ Perfil Melhorado
- **Showcase** - 3 personagens favoritos
- **Stats Detalhadas** - Win rate por modo
- **Banner Customizável** - Imagem de personagem
- **Bio & Cor** - Personalização completa
- **Histórico** - Últimas batalhas
- **Top Characters** - Mais usados e fortes

### ⚔️ Sistema de Formação
- **Elementos** - Fogo, Água, Elétrico, Terra, Vento, Luz, Trevas
- **Posições** - Front, Mid, Back (afeta dano)
- **Counters** - DPS > Support > Tank > DPS
- **Vantagens** - +50% dano com vantagem elemental

### 🔥 Boss Rush
- **5 Bosses** consecutivos
- **Sem cura** entre lutas
- **Dificuldade escalável** (100% → 220%)
- **Ranking semanal**
- **Recompensas progressivas** (até 27,500 gold)

### 🐉 Raids Cooperativas
- **Batalhas em grupo** (até 5 jogadores)
- **Bosses épicos** com mecânicas especiais
- **Recompensas compartilhadas**

### 🎲 Equipamentos
- **5 Slots** por personagem
- **Stats Boost** (HP, ATK, DEF, SPD)
- **Passivas Extras** (habilidades adicionais)
- **Raridades** (Comum → Mítico)
